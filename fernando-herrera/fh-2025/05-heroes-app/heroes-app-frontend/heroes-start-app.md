# Aplicacion de heroes app:

## Pasos para ejecutar proyecto
1. Clonar repo
2. Ubicarse en el proyecto
3. Crear el proyecto __.env__ con el __.env.example__ y llenar las variables
4. Instalar dependencias ```npm i```
5. Ejecutar: ```npm run dev```

# Para el testing en el backend poner en la terminal
```set PORT=3001```
```npm run start:dev```
